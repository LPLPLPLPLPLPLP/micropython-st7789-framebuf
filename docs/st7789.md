# st7789.py 显示屏驱动

## 函数/类 class ST7789(framebuf.FrameBuffer)

```python
display = ST7789(width, height, spi, dc, rst, cs=None)
```
- `width`: 显示屏宽
- `height`: 显示屏高
- `spi`: SPI对象
- `dc`: 数据/命令引脚
- `rst`: 复位引脚
- `cs`: 片选引脚


- 方法:

```python
display.show()
```
在屏幕上显示FrameBuffer的内容

```python
display.invert(mode:bool)
```
反转屏幕颜色

- `mode` 是否开启反转

```python
display.DrawText(text:str, x:int, y:int, color:int,
                 offset = 0, wrap:bool = False, w:int = None,
                 buffer:bytearray = None, slope:float = 0.0)
```
在屏幕上绘制文本（您需要下载字体文件SourceHanSans.mpy到您的esp32s3设备上）

- `x`: X坐标
- `y`: Y坐标
- `text`: 要绘制的文本
- `color`: 文本颜色
- `offset`: 字体偏移量
- `wrap`: 是否自动换行
- `w`: 文本宽度（如果文本过长，将会被切断）
- `buffer`: 用于绘制文本的缓冲区，默认为super()
- `slope`: 字体倾斜角度,默认不倾斜,可以达到斜体效果

```python
display.fill_round_rect(x:int, y:int, w:int, h:int, r:int, color:int)
```
在屏幕上指定位置绘制填充圆角矩形

- `x`: X坐标
- `y`: Y坐标
- `w`: 宽度
- `h`: 高度
- `r`: 圆角半径
- `color`: 颜色

```python
curved_side_rect(self, x:int, y:int, w:int, h:int, color:int)
```
在屏幕上指定位置绘制圆边矩形

- `x`: X坐标
- `y`: Y坐标
- `w`: 宽度
- `h`: 高度
- `color`: 颜色
