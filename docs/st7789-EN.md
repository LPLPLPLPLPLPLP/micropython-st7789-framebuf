# st7789 screen driver

## class ST7789(framebuf.FrameBuffer)

```python
display = ST7789(width, height, spi, dc, rst, cs=None)
```
- `width`: screen width
- `height`: screen height
- `spi`: SPI object
- `dc`: data/command pin
- `rst`: reset pin
- `cs`: chip select pin


- methods:

```python
display.show()
```
Show the content of FrameBuffer on the screen

```python
display.invert(mode:bool)
```
Invert the screen color

- `mode` whether to enable inversion

```python
display.DrawText(text:str, x:int, y:int, color:int,
                 offset = 0, wrap:bool = False, w:int = None,
                 buffer:bytearray = None, slope:float = 0.0)
```
Draw text on the screen(Warning: You need to download the font file SourceHanSans.mpy to your esp32s3 device)

- `x`: X coordinate
- `y`: Y coordinate
- `text`: text to be drawn
- `color`: text color
- `offset`: font offset
- `wrap`: whether to enable wrapping
- `w`: text width (if the text is too long, it will be cut off)
- `buffer`: buffer used for drawing text, default is super()
- `slope`: font slope angle, default is 0.0, which means no slope

```python
display.fill_round_rect(x:int, y:int, w:int, h:int, r:int, color:int)
```
Draw a filled rounded rectangle at the specified position on the screen

- `x`: X coordinate
- `y`: Y coordinate
- `w`: width
- `h`: height
- `r`: corner radius
- `color`: color

```python
curved_side_rect(self, x:int, y:int, w:int, h:int, color:int)
```
Draw a rounded rectangle with rounded corners at the specified position on the screen

- `x`: X coordinate
- `y`: Y coordinate
- `w`: width
- `h`: height
- `color`: color
